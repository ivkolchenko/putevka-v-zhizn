# Иллюстрации демонстрационного опроса

`study-desk.png` и `study-plans.png` созданы встроенным инструментом imagegen.
Команда `seed_demo_survey --with-images` копирует их в закрытое хранилище картинок
опросов. Исходники здесь нужны для воспроизводимого заполнения новой базы.

Промпты (по порядку файлов):

1. Use case: illustration-story. Asset type: image for a demonstration school survey block. Create one polished horizontal editorial illustration of a cozy student study desk, open notebook, a few books, laptop and small plant. Warm daylight, calm friendly atmosphere, clean restrained shapes and subtle paper texture. Wide 3:2 composition, suitable for a survey content card, no UI frame. No people, no readable text, no lettering, no logos, no watermark.
2. Use case: illustration-story. Asset type: image for a demonstration school survey block about study plans. Create one polished horizontal editorial illustration of a student planning desk with an unlabelled calendar, notebook, pencil and small compass, with an open window showing a calm path toward a university-like building in the distance. Calm friendly atmosphere, clean restrained shapes and subtle paper texture. Wide 3:2 composition, suitable for a survey content card, no UI frame. No people, no readable text, no lettering, no logos, no watermark.
